# 🏦 CA SaaS V2 — AI-Powered Tool for Chartered Accountants

> *"Built for India's 400,000+ practicing Chartered Accountants"*

---

## 🎯 Vision

CA SaaS V2 is India's most intelligent AI-powered accounting management platform — think **Tally**, but rebuilt from scratch with modern AI at its core.

We're solving the real pain points that 400,000+ Indian CAs face every single day:

- ⏰ Hours wasted reading and replying to ITD notices manually
- 📁 No intelligent system to manage client documents
- 🔍 No AI to detect anomalies in client financial data
- 📋 No smart tracker for notice deadlines

**We're building the solution.** 🚀

---

## ✨ Features

| Feature | Description | Status |
|---|---|---|
| 🔐 **Authentication** | CA Register & Login with JWT tokens |
| 👥 **Client Management** | Add, view, update, delete clients with PAN details |
| 📄 **Document Upload** | Upload ITR & notice PDFs with AI text extraction |
| 🤖 **AI Assistant** | Summarize documents, draft ITD notice replies, answer questions | 
| 🔍 **Anomaly Detection** | Scan all clients and flag suspicious financial patterns | 
| 📋 **Notice Tracker** | Track ITD notices with deadlines and status | 
| ⚡ **React Frontend** | Modern web interface for all features | 
| 🧠 **RAG System** | Indian tax law knowledge base for accurate AI replies |
| 🎨 **Dark UI Redesign** | Professional dark theme with modern UX |
| 📱 **Mobile App** | iOS & Android app for CAs on the go |
